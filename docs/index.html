Live spillway operations and Nettleton stage model

This site hosts the live ramp‑down decision tool for Glover Wilkins Lock and Dam and the supporting Nettleton gravel bar stage‑prediction methodology.

Use the dashboard to compare sudden closure vs gradual ramp‑down scenarios, and consult the methodology report for full model derivation, validation, and ecological context.

  • How to use the ramp‑down dashboard:

    1. Refresh live data. Click “Refresh Live USGS Data” to pull current flows and pool elevations at Fulton, Wilkins, and Bigbee.
    2. Confirm current operations. Use either “Select Operational Step”, “Enter Individual Gates”, or “Use USGS Gate Telemetry” to match the current Wilkins gate pattern.
    3. Set constraints. Specify the minimum navigation pool, maximum allowable stage decline (ft/hr), and how many intermediate steps you want in the ramp‑down.
    4. Review outcomes. The dashboard compares a sudden closure vs a gradual ramp‑down, reports pool drawdown and Nettleton depth, and provides a recommended schedule table.

    The live data are retrieved using the USGS dataRetrieval package and the Water Data APIs for continuous streamflow and stage. [USGS data are public‑domain and freely reusable with appropriate citation.]

  • The Nettleton stage model is a multiple linear regression relating water depth at the Nettleton gravel bar to upstream discharge at Fulton (USGS 02431000) and Wilkins Spillway discharge, derived from MOB36 operate log gate settings.

    Depth observations came from a HOBO pressure transducer installed at the Nettleton bar and converted to hourly depth above a fixed datum. Hourly upstream flow at Fulton and theoretical spillway discharge from the step table were aligned to build a complete modeling dataset.

    The selected model has the form Depth = −0.4386 + 0.002816·FLOW_FULTON + 0.001131·DISCHARGE_CFS with residual standard error of about 0.27 ft and adjusted R² of about 0.83 over the observed range. Alternative log‑depth and quadratic models were evaluated, but the linear form was chosen for transparency and operational usability.

    The full derivation, diagnostics, and validation figures are contained in nettleton-model.html .

  • Capacity curve – Wilkins pool.

    The ramp‑down calculations use a Wilkins capacity curve (elevation vs storage, in acre‑feet) to track how much pool storage is consumed during a controlled drawdown. The current implementation is based on a 243–247 ft elevation band and can be updated as improved survey or H&H products become available.

    Spillway step table.

    The spillway discharge table encodes gate‑by‑gate openings for each operational step and corresponding discharges across a range of tailwater conditions. Contributions to this table (e.g., updated rating curves, additional tailwater bands, or verified CFD/HEC‑RAS results) can be incorporated by editing the step table used in the Shiny app and in the methodology R Markdown.

    How to contribute:

    1. Open a pull request in the GitHub repository with:
      • Updated Wilkins capacity‑curve data (CSV or RDS), and/or
      • Updated spillway gate schedule / discharge table.
    2. Briefly document data sources (survey, modeling, or field measurements) and assumptions.
    3. Flag whether changes affect only the ramp‑down accounting, only the Nettleton model, or both.

    All hydrologic inputs from USGS are obtained via the public dataRetrieval interfaces to USGS Water Data for the Nation and the Water Quality Portal; users are encouraged to cite USGS and WQP data products following the guidance in the package documentation. [attached_file:1]

Ramp‑down dashboard (Shiny app)

Uses live USGS data (Fulton, Wilkins, Bigbee) via dataRetrieval to estimate ecological risk and recommend a step‑down schedule.
  • Recognizes current step from Wilkins gate telemetry or manual inputs.
  • Compares sudden closure vs gradual ramp‑down hydrographs.
  • Flags navigation constraints and ecological ramp‑rate exceedances.

Nettleton stage model methodology

Linear regression model relating Nettleton depth to upstream flow at Fulton and Wilkins Spillway discharge.
  • Derivation from HOBO depth sensor, USGS gages, and gate logs.
  • Model fit, diagnostics, and validation (R² ≈ 0.83, SE ≈ 0.27 ft).
  • Alternative fits (log‑depth, quadratic) and rationale for final choice.
